# Nkb-Ultralytics YOLOv8

Этот репозиторий является кастомным форком официального репозитория [Ultralytics](https://github.com/ultralytics/ultralytics), расширенным для поддержки продвинутых техник обучения и оптимизации моделей.

## Ключевые особенности

-   **Distillation:** Обучение моделей с помощью "учительских" моделей для повышения производительности без увеличения размера.
-   **Pruning:** Реализация структурного прунинга из `torch-pruning`.
-   **SAHI-based Training:** Реализована поддержка обучения на нарезанных изображениях (Slicing Aided Hyper Inference)
-   **Multi-task Learning:** Обучайте модель одновременно решать несколько задач (например, детекция объекта и определение его атрибута) с помощью специальной конфигурации датасета.

## Установка

1.  Клонируйте репозиторий:

    https://github.com/nkb-tech/ultralytics

## Как использовать

Все новые функции интегрированы в стандартный воркфлоу Ultralytics и могут быть активированы с помощью аргументов командной строки или через конфигурационные файлы.

### 1. Distillation

Этот метод передает "знания" от большой, предварительно обученной модели (учителя) к более маленькой модели (студенту). Это помогает студенту достичь более высокой точности.

**Параметры:**

-   `teacher` (str): Путь к весам модели-учителя (например, `yolov8l.pt`).
-   `temperature` (float): Температура для функции softmax, которая "смягчает" выходы учителя.
-   `alpha` (float): Коэффициент для взвешивания лосса дистилляции. Итоговый лосс = `alpha * distillation_loss + (1 - alpha) * original_loss`.

**Пример запуска:**

```bash
# Обучаем yolov8s (студент) с помощью yolov8l (учитель)
yolo train model=yolov8s.pt data=coco.yaml epochs=100 teacher=yolov8l.pt alpha=0.5 temperature=3.0
```

### 2. SAHI-based Training

Идеально подходит для датасетов с изображениями высокого разрешения (например, аэросъемка), где объекты могут быть очень маленькими. 

**Параметры:**


**Параметры:**

| Параметр           | Тип      | Описание                                                                                                                                                               |
| ------------------ | -------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `sahi`             | `bool`   | Включает (`True`) или выключает (`False`) режим обучения с нарезкой.                                                                                                    |
| `train_cut_strategy` | `str`    | Стратегия нарезки для обучающего набора. `grid` - равномерная сетка, `random_crop` - случайные вырезки.                                                                |
| `val_cut_strategy`   | `str`    | Стратегия нарезки для валидационного набора. Обычно `grid`.SAHI.                                                                                        |
| `crop_size`        | `int`    | Размер каждого квадратного кропа (например, `640` для нарезки на фрагменты 640x640 пикселей).                                                                              |
| `overlap_ratio`    | `float`  | Коэффициент пересечения соседних кропов в `grid` стратегии (от `0.0` до `1.0`). `0.2` означает 20% пересечения. Помогает не терять объекты на границах.                                     |
| `sampling_rate`    | `float`  | Для стратегии `random_crop`. Доля кропов, которые случайным образом выбираются из возможных (кол-во оценивается по `grid` стратегии с заданным `overlap_ratio`). `0.3` означает, что будет использовано 30% для каждого изображения от максимального кол-ва при `grid` стратегии.        |
| `crop_threshold`   | `int`    | Минимальный размер изображения (ширина или высота), при котором будет применяться `random_crop`.                                                                              |
| `bg_crop_prob`     | `float`  | Вероятность создания кропа из области фона (без объектов). Помогает модели лучше отличать фон и снижает число ложных срабатываний.                                      |
| `scale_range`      | `tuple`  | Диапазон случайного масштабирования для кропов, например, `(0.7, 1.3)`.                                                                                         |
| `erosion_factor`   | `float`  | `0.0` означает, что bbox объекта должен полностью находиться внутри кропа. Увеличение значения позволяет включать в обучение частично видимые объекты.                   |
| `full_image_prob`  | `float`  | Вероятность того, что вместо кропа на обучение будет подано полное изображение, сжатое до `crop_size`. Помогает модели сохранять контекст.                                |


**Пример запуска:**

```bash
# Обучение на датасете с большими изображениями, используя нарезку 640x640 с пересечением 20%
yolo train model=yolov8n.pt data=visdrone.yaml epochs=200 imgsz=640 sahi=True crop_size=640 overlap_ratio=0.2
```

### 3. Multi-task (Мультитаск-обучение)

Позволяет модели предсказывать не только основной класс объекта, но и его дополнительные атрибуты (например, "автомобиль" + "поврежденный"). Настройка происходит через `data.yaml`.

**Конфигурация `data.yaml`:**

1.  Параметр `nc` вычисляется автоматически, не надо его указывать
2.  Параметр `names` должен быть списком списков. Первый вложенный список — это основные классы. Последующие списки — это атрибуты для каждой дополнительной "головы" модели.

**Пример `data.yaml`:**
```yaml
path: /path/to/dataset
train: images/train
val: images/val

# names: [[основные классы], [атрибуты состояния]]
names:
  - ['truck', 'car', 'vehicle']  # Задача 1: Классификация транспорта
  - ['undamaged', 'damaged']      # Задача 2: Определение состояния
```

**Формат разметки (labels):**

Каждая строка в `.txt` файле разметки должна иметь формат: `<class_id> <attribute_id_1> ... <attribute_id_N> <x_center> <y_center> <width> <height>`.

-   `<class_id>`: Индекс класса из первого списка в `names`.
-   `<attribute_id_...>`: Индекс атрибута из соответствующего списка в `names`.

**Пример файла разметки `image1.txt`:**
```txt
# Объект 1: 'car' (индекс 1) и 'damaged' (индекс 1)
1 1 0.5 0.5 0.2 0.3

# Объект 2: 'truck' (индекс 0) и 'undamaged' (индекс 0)
0 0 0.8 0.6 0.1 0.15
```

**Пример запуска:**
Запуск происходит как обычное обучение. Модель сама поймет, что нужно обучать несколько голов на основе `data.yaml`.
```bash
yolo train model=yolov8s.pt data=my_multitask_data.yaml epochs=100
```

### 4. Pruning (Сжатие / Прунинг модели)

Этот режим позволяет уменьшить размер модели и ускорить ее работу путем удаления избыточных каналов/слоев. Процесс состоит из двух этапов: прунинг (`compress`) и дообучение (`finetune`).

> ⚠️ **Важное замечание:** Текущая реализация `resume` работает нестабильно. Настоятельно рекомендуется запускать прунинг и дообучение как два отдельных, последовательных шага, чтобы не потерять прогресс.

**Рекомендуемый воркфлоу:**

1.  **Этап 1: Прунинг.** Запустить сжатие с флагом `do_prune=True` и `do_finetune=False`. Это создаст "обрезанную" архитектуру модели и сохранит ее.
2.  **Этап 2: Дообучение.** Запустить обучение с флагом `do_prune=False` и `do_finetune=True`, указав в `model` путь к модели, полученной на первом этапе.

**Запуск через CLI (рекомендуемый способ):**

Для запуска используется режим `compress`:
```bash
yolo detect compress model=... data=... [ПАРАМЕТРЫ_ПРУНИНГА]
```

**Пример:**

```bash
# Этап 1: Прунинг. Сжимаем модель yolov8s.pt в 2 раза по GFLOPs.
yolo detect compress model=yolov8s.pt data=coco128.yaml do_prune=True do_finetune=False speed_up=2.0 prune_method=group_taylor sl_epochs=50 name=pruned_yolov8s_x2

# Этап 2: Дообучение. Тюним модель, полученную после прунинга.
# Путь к модели будет примерно 'runs/detect/pruned_yolov8s_x2/pruned_model.pt'
yolo detect compress model=runs/detect/pruned_yolov8s_x2/pruned_model.pt data=coco128.yaml do_prune=False do_finetune=True epochs=100 name=finetuned_yolov8s_x2
```

**Параметры прунинга:**

| Параметр           | Тип     | Описание                                                                                                                  |
| ------------------ | ------- | ------------------------------------------------------------------------------------------------------------------------- |
| `do_prune`         | `bool`  | `True`, чтобы запустить этап прунинга.                                                                                    |
| `do_finetune`      | `bool`  | `True`, чтобы запустить этап дообучения. Лучше использовать `False` на первом этапе и `True` на втором.                         |
| `prune_method`     | `str`   | Метод прунинга. Доступные: `random`, `l1`, `lamp`, `slim`, `group_slim`, `group_sl`, `group_taylor`, `group_norm`, `growing_reg`. |
| `speed_up`         | `float` | Целевой коэффициент уменьшения GFLOPs (например, `2.0` для уменьшения в 2 раза).                                        |
| `global_pruning`   | `bool`  | `True` для применения прунинга глобально по всей модели, `False` — послойно.                                              |
| `sl_epochs`        | `int`   | Количество эпох для "Sparsity Learning" (обучения разреженности), если метод это поддерживает (`slim`, `group_sl`).      |
| `sl_hyp`           | `str`   | Путь к файлу с гиперпараметрами для Sparsity Learning (например, `ultralytics/cfg/hyp.scratch.sl.yaml`).                 |
| `reg`              | `float` | Коэффициент регуляризации для методов, использующих ее (например, `growing_reg`).                                         |

**Дополнительные замечания:**
-   **Пользовательские модели:** Если вы пруните не стандартную YOLOv8, а кастомную архитектуру, вам может потребоваться вручную отредактировать список игнорируемых слоев в файле `ultralytics/models/yolo/detect/compress.py`.
-   **Оптимизация C2f:** В процессе прунинга модули `C2f` автоматически заменяются на более быстрые `C2f_Faster` (см. `c2f_transfer.py`).
-   **Примеры параметров:** Удачные комбинации гиперпараметров для прунинга можно найти в файле `compress.md` в корне репозитория.
